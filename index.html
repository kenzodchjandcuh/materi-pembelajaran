Pengenalan Lengkap C++

C++ adalah bahasa pemrograman yang dikembangkan oleh Bjarne Stroustrup pada tahun 1979 sebagai ekstensi dari bahasa C. Nama "C++" berasal dari operator increment (++) di C, yang menunjukkan bahwa C++ adalah versi yang "diperbaiki" dari C. C++ dirilis secara resmi pada tahun 1983 dan telah menjadi salah satu bahasa pemrograman paling populer dan kuat di dunia.

Sejarah dan Evolusi C++

C++ awalnya dikembangkan untuk memungkinkan pemrograman berorientasi objek sambil mempertahankan efisiensi dan fleksibilitas bahasa C. Seiring waktu, C++ telah berkembang melalui beberapa standar:

  • C++98: Standar pertama yang diterbitkan oleh ISO.
  • C++03: Revisi minor dari C++98.
  • C++11: Pembaruan besar dengan fitur-fitur modern seperti auto, lambda, dan smart pointers.
  • C++14, C++17, C++20: Pembaruan berkelanjutan dengan fitur-fitur baru.

Fitur Utama C++

C++ mendukung beberapa paradigma pemrograman:

  • Pemrograman Prosedural: Mirip dengan C, menggunakan fungsi dan prosedur.
  • Pemrograman Berorientasi Objek: Mendukung class, inheritance, polymorphism, encapsulation.
  • Pemrograman Generic: Menggunakan template untuk kode yang dapat digunakan ulang.
  • Metaprogramming: Kemampuan untuk menulis kode yang menghasilkan kode lainnya.

Keunggulan C++

  • Performa Tinggi: Dekat dengan hardware, cocok untuk aplikasi yang membutuhkan kecepatan.
  • Kontrol Memori: Programmer memiliki kontrol penuh atas manajemen memori.
  • Portabilitas: Kode C++ dapat dikompilasi di berbagai platform.
  • Libraries Kaya: Standard Template Library (STL) menyediakan struktur data dan algoritma siap pakai.
  • Komunitas Besar: Banyak dukungan dan sumber belajar.

Kekurangan C++

  • Kompleksitas: Kurva belajar yang curam, terutama untuk pemula.
  • Manajemen Memori Manual: Rentan terhadap memory leaks dan bugs jika tidak hati-hati.
  • Verbose: Kode sering lebih panjang dibanding bahasa lain.

Contoh Kode C++ Sederhana

#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}

Kode di atas adalah program "Hello, World!" klasik yang mencetak teks ke konsol.

Contoh Kode C++ dengan Class (OOP)

#include <iostream>
#include <string>
using namespace std;

class Mahasiswa {
private:
    string nama;
    int umur;
public:
    Mahasiswa(string n, int u) {
        nama = n;
        umur = u;
    }
    
    void tampilkanInfo() {
        cout << "Nama: " << nama << endl;
        cout << "Umur: " << umur << endl;
    }
};

int main() {
    Mahasiswa mhs("John Doe", 20);
    mhs.tampilkanInfo();
    return 0;
}

Contoh di atas menunjukkan penggunaan class dalam C++ untuk membuat objek Mahasiswa.

Template dalam C++

#include <iostream>
using namespace std;

template <typename T>
T maksimum(T a, T b) {
    return (a > b) ? a : b;
}

int main() {
    cout << "Maksimum int: " << maksimum(5, 10) << endl;
    cout << "Maksimum double: " << maksimum(3.14, 2.71) << endl;
    return 0;
}

Template memungkinkan fungsi maksimum bekerja dengan berbagai tipe data.

Penggunaan STL (Standard Template Library)

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> angka = {3, 1, 4, 1, 5, 9, 2, 6};
    
    cout << "Angka sebelum sorting: ";
    for(int n : angka) cout << n << " ";
    cout << endl;
    
    sort(angka.begin(), angka.end());
    
    cout << "Angka setelah sorting: ";
    for(int n : angka) cout << n << " ";
    cout << endl;
    
    return 0;
}

STL menyediakan container seperti vector dan algoritma seperti sort.

Kompilasi dan Eksekusi C++

Untuk menjalankan program C++, Anda perlu compiler seperti g++ (untuk GCC) atau Visual C++. Contoh kompilasi:

g++ program.cpp -o program
./program

Aplikasi C++

C++ digunakan dalam berbagai bidang:

  • Game Development: Engine seperti Unreal Engine.
  • System Programming: OS, driver, embedded systems.
  • Aplikasi Desktop: Software seperti Adobe Photoshop.
  • High-Performance Computing: Simulasi ilmiah, AI.
  • Web Servers: Beberapa server web seperti Apache menggunakan C++.

Pengenalan Lengkap HTML

HTML (HyperText Markup Language) adalah bahasa markup standar yang digunakan untuk membuat dan merancang halaman web. HTML bukanlah bahasa pemrograman, melainkan bahasa markup yang menggunakan tag untuk mendefinisikan struktur dan konten halaman web. HTML dikembangkan oleh Tim Berners-Lee pada tahun 1991 dan telah berkembang melalui berbagai versi hingga HTML5 saat ini.

Sejarah HTML

  • HTML 1.0 (1991): Versi awal yang sederhana.
  • HTML 2.0 (1995): Standar pertama dari IETF.
  • HTML 3.2 (1997): Menambahkan dukungan untuk tabel dan scripting.
  • HTML 4.01 (1999): Versi stabil dengan fokus pada semantic markup.
  • XHTML (2000): Versi XML-compliant dari HTML.
  • HTML5 (2014): Versi terbaru dengan fitur multimedia dan semantic elements.

Struktur Dasar HTML

Setiap dokumen HTML dimulai dengan DOCTYPE declaration, diikuti oleh elemen <html>, <head>, dan <body>.

Pengenalan Lengkap CSS

CSS (Cascading Style Sheets) adalah bahasa stylesheet yang digunakan untuk menggambarkan presentasi dokumen yang ditulis dalam HTML atau XML. CSS menggambarkan bagaimana elemen-elemen HTML harus ditampilkan di layar, kertas, atau media lainnya. CSS dikembangkan oleh W3C (World Wide Web Consortium) dan pertama kali dirilis pada tahun 1996.

Sejarah CSS

  • CSS1 (1996): Versi pertama dengan basic styling.
  • CSS2 (1998): Menambahkan positioning dan media types.
  • CSS2.1 (2004): Revisi dari CSS2.
  • CSS3 (2011+): Modular dengan fitur-fitur canggih seperti animations, flexbox, grid.

Cara Menggunakan CSS

1. Inline CSS

<p style="color: red; font-size: 20px;">Teks ini berwarna merah</p>

2. Internal CSS

<style>
p {
    color: blue;
    font-family: Arial;
}
</style>

3. External CSS (Recommended)

<link rel="stylesheet" href="style.css">

Selector CSS

Basic Selectors

  • Element Selector: p { color: red; }
  • Class Selector: .classname { font-size: 14px; }
  • ID Selector: #idname { background-color: yellow; }
  • Universal Selector: * { margin: 0; }

Combinator Selectors

  • Descendant: div p { color: blue; }
  • Child: ul > li { list-style: none; }
  • Adjacent Sibling: h1 + p { margin-top: 0; }
  • General Sibling: h1 ~ p { color: gray; }

Pseudo-classes dan Pseudo-elements

a:hover { color: red; }          /* Pseudo-class */
p::first-line { font-weight: bold; } /* Pseudo-element */

Box Model

Setiap elemen HTML direpresentasikan sebagai rectangular box dengan:

  • Content: Konten aktual
  • Padding: Ruang di sekitar konten
  • Border: Garis di sekitar padding
  • Margin: Ruang di luar border
.box {
    width: 200px;
    padding: 20px;
    border: 2px solid black;
    margin: 10px;
}

Layout dengan CSS

Display Property

  • block: Elemen mengambil lebar penuh, line break sebelum dan sesudah
  • inline: Elemen mengambil lebar sesuai konten, tidak ada line break
  • inline-block: Kombinasi block dan inline
  • none: Elemen disembunyikan
  • flex: Menggunakan Flexbox
  • grid: Menggunakan CSS Grid

Positioning

  • static: Default positioning
  • relative: Posisi relatif terhadap posisi normal
  • absolute: Posisi absolut terhadap ancestor positioned
  • fixed: Posisi fixed terhadap viewport
  • sticky: Sticky positioning

Flexbox

Flexbox adalah layout model satu dimensi untuk mendistribusikan space dan menyelaraskan item.

.container {
    display: flex;
    justify-content: space-between; /* horizontal alignment */
    align-items: center; /* vertical alignment */
}

.item {
    flex: 1; /* grow factor */
}

CSS Grid

CSS Grid adalah layout system dua dimensi untuk web.

.grid-container {
    display: grid;
    grid-template-columns: 1fr 2fr 1fr;
    grid-template-rows: auto;
    gap: 10px;
}

Responsive Design

Media Queries

@media (max-width: 768px) {
    .container {
        flex-direction: column;
    }
}

Viewport Meta Tag

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Animations dan Transitions

Transitions

.button {
    transition: background-color 0.3s ease;
}

.button:hover {
    background-color: blue;
}

Keyframes Animation

@keyframes slideIn {
    from { transform: translateX(-100%); }
    to { transform: translateX(0); }
}

.element {
    animation: slideIn 1s ease-in-out;
}

CSS Variables (Custom Properties)

:root {
    --primary-color: #007bff;
    --font-size: 16px;
}

.element {
    color: var(--primary-color);
    font-size: var(--font-size);
}

Best Practices CSS

  • Gunakan external CSS untuk maintainability
  • Ikuti konvensi penamaan yang konsisten (BEM, SMACSS)
  • Minimize specificity conflicts
  • Gunakan CSS variables untuk konsistensi
  • Optimalkan untuk performance (minify, compress)
  • Test di berbagai browser

Pengenalan Lengkap JavaScript

JavaScript adalah bahasa pemrograman tingkat tinggi, interpreted, dan multiparadigm yang dikembangkan oleh Brendan Eich pada tahun 1995 untuk Netscape Navigator. JavaScript awalnya bernama Mocha, lalu LiveScript, dan akhirnya JavaScript. Meskipun namanya mirip dengan Java, keduanya adalah bahasa yang berbeda. JavaScript adalah bahasa pemrograman yang paling banyak digunakan di dunia dan merupakan salah satu teknologi inti web modern.

Sejarah JavaScript

  • 1995: Dibuat oleh Brendan Eich dalam 10 hari
  • 1997: ECMAScript 1 (standarisasi)
  • 2009: Node.js lahir, JS bisa berjalan di server
  • 2015: ES6/ES2015 dengan fitur modern
  • 2020+ : Update tahunan ES2020, ES2021, dll.

Cara Menggunakan JavaScript

1. Inline JavaScript

<button onclick="alert('Hello!')">Klik</button>

2. Internal JavaScript

<script>
function sayHello() {
    alert('Hello, World!');
}
</script>

3. External JavaScript (Recommended)

<script src="script.js"></script>

Variabel dan Tipe Data

Declaration

var oldWay = "deprecated";     // var (global scope)
let modern = "recommended";     // let (block scope)
const constant = "immutable";    // const (block scope, immutable)

Tipe Data

  • Primitive: string, number, boolean, undefined, null, symbol, bigint
  • Object: object, array, function, date, regexp
let str = "Hello";           // String
let num = 42;                // Number
let bool = true;             // Boolean
let arr = [1, 2, 3];         // Array
let obj = {name: "John"};    // Object

Operator

Arithmetic Operators

let a = 10, b = 3;
console.log(a + b);  // 13 (addition)
console.log(a - b);  // 7 (subtraction)
console.log(a * b);  // 30 (multiplication)
console.log(a / b);  // 3.333... (division)
console.log(a % b);  // 1 (modulus)
console.log(a ** b); // 1000 (exponentiation)

Comparison Operators

console.log(5 == "5");   // true (loose equality)
console.log(5 === "5");  // false (strict equality)
console.log(5 != "5");   // false
console.log(5 !== "5");  // true
console.log(5 > 3);      // true
console.log(5 >= 5);     // true

Control Flow

Conditional Statements

if (condition) {
    // code to execute if condition is true
} else if (anotherCondition) {
    // code to execute if anotherCondition is true
} else {
    // code to execute if all conditions are false
}

switch (expression) {
    case value1:
        // code
        break;
    case value2:
        // code
        break;
    default:
        // code
}

Loops

// For loop
for (let i = 0; i < 5; i++) {
    console.log(i);
}

// While loop
let i = 0;
while (i < 5) {
    console.log(i);
    i++;
}

// For...of loop (for arrays)
let arr = [1, 2, 3];
for (let item of arr) {
    console.log(item);
}

// For...in loop (for objects)
let obj = {a: 1, b: 2};
for (let key in obj) {
    console.log(key, obj[key]);
}

Function Declaration

Asynchronous JavaScript

Callbacks

Pengenalan Lengkap PHP

PHP (Hypertext Preprocessor) adalah bahasa scripting open-source yang banyak digunakan untuk pengembangan web server-side. PHP dikembangkan oleh Rasmus Lerdorf pada tahun 1994 sebagai kumpulan script Perl untuk melacak pengunjung website. Nama "PHP" awalnya adalah "Personal Home Page", tapi kemudian diubah menjadi "Hypertext Preprocessor" untuk mencerminkan fungsinya yang lebih luas. PHP adalah bahasa yang paling populer untuk backend web development dan merupakan komponen inti dari teknologi seperti WordPress, Laravel, dan banyak CMS lainnya.

Sejarah PHP

  • 1994: Rasmus Lerdorf membuat PHP/FI (Personal Home Page/Forms Interpreter)
  • 1997: PHP 3 dirilis dengan dukungan OOP dasar
  • 2000: PHP 4 dengan Zend Engine
  • 2004: PHP 5 dengan OOP yang lebih baik
  • 2015: PHP 7 dengan performa yang sangat meningkat
  • 2020: PHP 8 dengan fitur modern seperti JIT compiler

Keunggulan PHP

  • Mudah Dipelajari: Syntax yang mirip dengan C/Java
  • Open Source: Gratis dan komunitas besar
  • Cross-Platform: Berjalan di Windows, Linux, macOS
  • Database Integration: Dukungan luas untuk berbagai database
  • Framework Kaya: Laravel, Symfony, CodeIgniter, dll.
  • Hosting Luas: Hampir semua hosting web mendukung PHP

Instalasi dan Setup

Untuk menjalankan PHP, Anda perlu:

  • Web server (Apache, Nginx)
  • PHP interpreter
  • Database (MySQL, PostgreSQL) - opsional

Pilihan mudah: Install XAMPP (Windows) atau MAMP (macOS) yang menyediakan semua komponen.

// Create connection
$conn = new mysqli($servername, $username, $password, $dbname);

// Check connection
if ($conn->connect_error) {
    die("Connection failed: " . $conn->connect_error);
}

// Select data
$sql = "SELECT id, name FROM users";
$result = $conn->query($sql);

if ($result->num_rows > 0) {
    while($row = $result->fetch_assoc()) {
        echo "ID: " . $row["id"] . " - Name: " . $row["name"] . "<br>";
    }
}

$conn->close();
?>

Object-Oriented PHP

<?php
class Car {
    public $brand;
    
    public function __construct($brand) {
        $this->brand = $brand;
    }
    
    public function getBrand() {
        return $this->brand;
    }
}

$car = new Car("Toyota");
echo $car->getBrand();  // "Toyota"
?>
