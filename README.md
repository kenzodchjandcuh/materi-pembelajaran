# Materi Pembelajaran Coding

## 📚 Deskripsi Proyek

Materi Pembelajaran Coding adalah sebuah website interaktif yang dirancang untuk membantu pemula belajar dasar-dasar programming. Website ini menyediakan penjelasan lengkap tentang berbagai bahasa pemrograman populer dengan tampilan yang modern dan menarik menggunakan tema biru neon.

## 🎯 Tujuan

- Memberikan pemahaman komprehensif tentang bahasa pemrograman dasar
- Menyediakan contoh kode praktis yang dapat langsung dicoba
- Memperkenalkan konsep-konsep programming melalui interface yang user-friendly
- Membantu pemula dalam memulai perjalanan programming mereka

## 🚀 Fitur Utama

### 📖 Materi Pembelajaran Lengkap
- **C++**: Pemrograman berorientasi objek, template, STL
- **HTML**: Struktur web, semantic elements, multimedia
- **CSS**: Styling, layout, responsive design, animations
- **JavaScript**: DOM manipulation, events, asynchronous programming
- **PHP**: Server-side scripting, database integration, frameworks

### 🎨 Desain Modern
- Tema biru neon yang eye-catching
- Animasi dan transisi yang smooth
- Responsive design untuk semua perangkat
- Interface yang intuitif dan mudah dinavigasi

### 💻 Interaktivitas
- Tombol interaktif dengan efek hover
- Form input untuk demonstrasi JavaScript
- Smooth scrolling navigation
- Animasi scroll untuk meningkatkan user experience

### 👨‍💻 Profil Pengembang
- Informasi lengkap tentang developer
- Link ke portfolio dan kontak
- Statistik pengalaman programming

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Struktur dan konten website
- **CSS3**: Styling dan layout dengan fitur modern
- **JavaScript (ES6+)**: Interaktivitas dan DOM manipulation
- **Font**: Arial (web-safe font)

## 🚀 Cara Menjalankan

1. **Clone atau Download** folder proyek ini
2. **Buka file** `index.html` di browser web favorit Anda
3. **Navigasi** melalui menu untuk menjelajahi materi
4. **Interaksi** dengan elemen-elemen di halaman

### Persyaratan Sistem
- Browser web modern (Chrome, Firefox, Safari, Edge)
- Tidak memerlukan server atau instalasi tambahan
- Mendukung semua perangkat (desktop, tablet, mobile)

## 📖 Cara Penggunaan

1. **Navigasi**: Gunakan menu di header untuk melompat ke section tertentu
2. **Belajar**: Baca penjelasan dan lihat contoh kode di setiap section
3. **Praktik**: Coba interaksi dengan tombol dan form yang tersedia
4. **Eksplorasi**: Kunjungi profil pengembang untuk informasi lebih lanjut

## 🎨 Tema dan Styling

Website ini menggunakan tema biru neon yang mencakup:
- **Background**: Gradien gelap dengan efek depth
- **Text**: Warna biru neon (#00FFFF) dengan glow effect
- **Borders**: Outline biru neon pada elemen interaktif
- **Shadows**: Box-shadow dengan efek neon glow
- **Animations**: Hover effects dan transitions yang smooth
